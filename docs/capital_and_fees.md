# (b) 資金制約と手数料：提案と比較

資金 **200万円** で寄り引け（前日売買代金TOP20・1日で寄り→引け）を回す際の現実的な建て方と、
手数料でどれだけ負けるかの比較。`oc_strategy/sizing.py` ＋ `scripts/run_oc_cost_compare.py` で再現できる。

```bash
python scripts/run_oc_cost_compare.py --capital 2000000
# 出力: results/oc_cost_compare.csv / .png
```

---

## 問題の核心
1. **値がさ株が買えない**：単元(100株)だと 4–5万円株は 1単元=400–500万円。200万では 1単元すら買えず、
   20銘柄均等は不可能（動画でも「1日2,3銘柄」L290–301）。→ **銘柄数が減り、シグナルを再現できない（sizing_drag）**。
2. **デイリーの寄り引け＝年約252回の往復売買**。→ **1往復あたりの手数料が小さくても 252倍に効く（fee_drag）**。
   - ざっくり `年間手数料drag ≈ (買率＋売率＋スプレッド×2) × 252`。0.1%/往復でも ≈ 25%/年。

劣化を2要因に分けて評価する：**sizing_drag（制約）** と **fee_drag（手数料・スリッページ）**。

---

## 建て方の選択肢と提案

| 方式 | 空売り | 寄り/引け約定 | 200万での分散 | 手数料の現実 | 評価 |
|---|---|---|---|---|---|
| **単元＋一日信用（両建）** | ✅可 | ✅可（ザラ場OK） | ✗ 数銘柄に集中 | 大手は**売買0円**＋スリッページ | ◎ **戦略に最も忠実**（ショート維持）。集中はリスク |
| 単元＋現物（ロングのみ） | ✗ | ✅可 | ✗ 集中 | 通常手数料 | △ ショート喪失で**符号が反転し負けに転落**しうる |
| 端株（SBI S株 等） | ✗ | △ **引け約定不可**が多い（寄り中心） | ✅ 多銘柄に分散 | S株は**ほぼ0**／他社は%課金 | ○（条件付き）ロング専用＋約定タイミング近似 |
| 端株（楽天かぶミニ・リアルタイム） | ✗ | ○ ザラ場可 | ✅ | **片道0.22%スプレッド** | ✗ 往復0.44%×252≈111%/年 → 壊滅 |
| 端株（マネックス ワン株） | ✗ | △ | ✅ | **売却0.55%** | ✗ 同上で壊滅 |
| 端株（moomoo） | ✗ | ★要確認 | ✅ | ★**要確認** | %課金なら壊滅、実質0なら○ |

### 提案（推奨）
- **本命：単元＋一日信用**。空売りを維持できるのでショート側（画像で稼ぎ頭）を捨てずに済む。
  手数料0円の証券会社（大手のデイトレ信用）を使い、コストは主にスリッページ。
  200万では集中するので、**銘柄数とサイズの制約をそのままフォワードに織り込む**（このモジュールが対応）。
- **端株は「ロング専用の安価な分散版」**として“別戦略”扱い。使うなら **実質0手数料（SBI S株／moomoo が0なら）一択**。
  ただし **空売り不可＝戦略が long-only に変質**し、**引けのタイミングで正確に売れない**ため寄り引けは近似になる。
- **%課金の端株（楽天かぶミニ・マネックス）はデイリー寄り引けには不可**（手数料倒れ）。
- 手数料が重いなら、**売買頻度を落とす／一部を翌日持ち越す**等で年間往復回数を減らすのが効く。

## 比較の見方（合成データでの例）
`fee_drag(%pt/yr)` が「手数料そのもの」で負ける量。`sizing_drag` は「制約（銘柄数・単元丸め・ショート不可）」で負ける量。

合成サンプルでの傾向（**実データでないので絶対値に意味はない／構造だけ見る**）：
- 一日信用（スリッページ3bps仮定）→ fee_drag ≈ 15%pt/yr。**わずかな滑りでも往復252回で巨大化**。
- 端株 %課金（0.22–0.55%）→ fee_drag 80–94%pt/yr。**完全に手数料倒れ**。
- 端株 実質0（SBI S株／moomoo=0想定）→ fee_drag ≈ 0。ロング専用ぶんの差（sizing_drag）だけ。

## moomoo について（要確認ポイント）
- 端株（単元未満株）で **日本株の寄り→引け（同日往復）が約定可能か**、**空売りできるか**、**手数料体系**。
- もし %課金（約定代金比）なら、上表の通り**デイリー寄り引けは手数料倒れ**になる可能性が高い。
- 実質0なら、ロング専用の分散版として有効。実料金が分かれば `FEES["moomoo_hakabu"]` を更新して再実行で即比較できる。

> 本コードは検証用。手数料・約定可否は各社規約と実測で必ず確認すること。
